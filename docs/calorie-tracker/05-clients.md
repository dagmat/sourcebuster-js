# 05. Клиентские приложения

[← к оглавлению](README.md)

## 1. Состав клиентов

| Клиент | Технология (рекомендация) | Пользователи | Назначение |
|---|---|---|---|
| Мобильное приложение iOS/Android | Flutter (одна кодовая база) | Все участники | Запись еды, дневной экран, план, отчёты |
| Режим «кухонный планшет» | То же приложение, режим общего устройства | Семья | Запись за любого участника, план готовки на сегодня, список покупок |
| Веб-кабинет | Flutter Web или React (SPA) | Администратор, взрослые | Каталог и рецепты, отчёты, план недели, качество распознавания, управление устройствами |
| Виджеты и быстрые действия | Нативные расширения | Все | Кнопки «Фото» и «Голос» на главном экране телефона; ярлыки Siri / Google Assistant («Запиши в рацион…») |

## 2. Локальное хранилище и офлайн-режим
- Локальная БД (SQLite через Drift/Isar) — копия нужных данных: каталог, рецепты, посуда, открытые партии, план на 2 недели, записи за 30 дней, нормы.
- **Исходящая очередь** операций и медиафайлов (см. [01-server.md](01-server.md), раздел 5). Индикатор синхронизации на главном экране: «всё синхронизировано» / «ожидает отправки: 3».
- **Офлайн-доступно:** создание записи (фото/голос сохраняются как черновик), ручной выбор из каталога, повтор приёма, просмотр дневного экрана (по локальным данным), плана и списка покупок.
- **Локальный быстрый поиск без сервера** (опционально, этап 2+): при отсутствии сети — подсказка блюд по контекстному приору (кто/когда), рассчитанному сервером и синхронизированному на устройство.

## 3. Основные экраны мобильного приложения

### 3.1. Главный экран «Сегодня»
- Кольцо энергии: съедено / норма / план; полоски Б, Ж, У.
- Лента приёмов пищи за день: карточки с миниатюрой фото, позициями и калориями; запланированные, но ещё не записанные приёмы — серыми карточками с кнопкой «Съел по плану».
- **Две большие кнопки внизу: «📷 Фото» и «🎤 Голос»** — основное действие доступно одним касанием. Дополнительно: «⌨ Текст», «▦ Штрихкод», «↻ Повторить».
- Переключатель участника (для записей за ребёнка).

### 3.2. Сценарий «Фото»
1. Касание «Фото» → сразу камера (без промежуточных экранов). Подсказка-рамка; переключатели режима: «Тарелка» / «До и после» / «Этикетка».
2. Снимок → сжатие → загрузка → экран результата с анимацией «распознаю» и прогрессом этапов (по WebSocket). Во время ожидания можно зажать кнопку микрофона и добавить голосовую подпись.
3. Результат:
   - `auto_save` → короткая карточка-уведомление «Сохранено: …» и возврат на главный экран; кнопка «Исправить».
   - `pick_from_top3` → на фото подсвечены области; под проблемной позицией — 3 крупные кнопки вариантов + «Другое»; остальные позиции уже заполнены; кнопка «Готово».
   - `ask` → один вопрос с вариантами.
4. Редактирование позиции: касание → выбор блюда (поиск по каталогу с подсказками), количество (штуки ±, ползунок массы с отметками «типичная порция», «как в прошлый раз»), партия, участники/доли.

### 3.3. Сценарий «Голос»
1. Удерживать кнопку (или касание — старт, касание — стоп; автостоп по паузе 1,5 с).
2. Во время речи показывается живая расшифровка (локальное распознавание ОС для отображения; финальное — на сервере).
3. Результат — список позиций с разбором; те же решения, что для фото.
4. Голосовое исправление последней записи: «Нет, три котлеты» — на экране результата или в течение 30 минут после записи.

### 3.4. Каталог
Список блюд семьи с поиском и фильтрами (категория, «требуют уточнения», «мало фото»). Карточка блюда: фото-эталоны (можно удалить ошибочные), синонимы, рецепт и состав, типичные порции участников, история. Мастер добавления рецепта голосом/по фото текста.

### 3.5. Партии
Кнопка «Приготовил»: выбор рецепта → изменения → (опционально) взвешивание кастрюли. Список открытых партий с остатком и сроком. Действия: «Взвесить остаток», «Доели», «Выбросили остаток».

### 3.6. План
Неделя по дням; слоты; блюда участников; значки статуса соблюдения; кнопки «Заменить», «Закрепить», «Пересобрать»; список покупок с отметками; пояснение плана.

### 3.7. Отчёты
Дневной, недельный, месячный (см. [03-nutrition.md](03-nutrition.md), раздел 6). «Светофор» нутриентов с переходом к источникам и рекомендациям. График веса и энергии.

### 3.8. Профиль и настройки
Данные профиля и вес (быстрый ввод веса), цели и нормы, привычки (кофе с молоком), напоминания и тихие часы, видимость данных для других участников, ПИН/биометрия.

### 3.9. Режим обучения (первые недели)
Отдельная плашка на главном экране: «Обучение: выучено 42 блюда, точность 91 %», задания на сегодня («Сфотографируйте тарелку для супа рядом с картой», «Взвесьте порцию плова»), ссылка на мастер настройки.

## 4. Веб-кабинет
| Раздел | Функции |
|---|---|
| Каталог и рецепты | Массовое редактирование, слияние/разделение блюд, работа с эталонными фото (сетка, удаление неверных), маппинг продуктов на справочник |
| Отчёты | Все отчёты в расширенном виде, сравнение участников, экспорт PDF/CSV |
| План | Удобное редактирование недели на большом экране, шаблоны недели, расписание участников |
| Качество распознавания | Метрики, матрица путаницы, предложения системы (слить, доснять), просмотр конкретных задач распознавания с этапами |
| Администрирование | Участники, приглашения, устройства, права видимости, ключи и лимиты AI, расходы, состояние сервера, бэкапы, экспорт/удаление данных |

## 5. Требования к UX
- Запись приёма пищи в типичном случае — ≤ 2 касания после съёмки/речи.
- Открытие приложения до готовности камеры — ≤ 1,5 с.
- Все действия с результатом распознавания отменяемы.
- Язык — русский; поддержка системного размера шрифта, тёмной темы, VoiceOver/TalkBack для основных сценариев.
- Никаких «стыдящих» формулировок о еде; нейтральный тон уведомлений; для детей — без акцента на калориях (настраивается).
